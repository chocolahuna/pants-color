# ハァハァ、お姉さんパンツ何色？（PWA版）

正式採用アイコン：黒〜紺の背景＋虹色パンツ＋スポイト

## 公開するには

このZIPを展開し、**index.html / manifest.webmanifest / service-worker.js / favicon.ico / icons フォルダ**を、ディレクトリ構造を変えずに HTTPS 対応の静的Webホスティングへアップロードしてください。
GitHub Pages、Netlify、Vercelなどで利用できます。インストール可能なPWAとして公開できます。

- **PC / AndroidのChrome・Edge**：公開URLを開き、アドレスバーのインストール操作、または画面に表示される「＋ アプリとしてインストール」を押します（環境により表示方法が異なります）。
- **iPhone / iPadのSafari**：共有メニューから「ホーム画面に追加」を選びます。
- **オフライン**：オンラインで初回アクセスしてService Workerが導入されたあと、キャッシュ済み画面をオフラインで開けます。

**注意：** `file://` で直接index.htmlを開いても、一般的なブラウザではService Workerを登録できず、PWAとしてのインストール機能は動作しません。HTTPS または http://localhost（ローカル検証）からアクセスしてください。

ローカルテスト例：展開フォルダで `python -m http.server 8000` を実行し、`http://localhost:8000/` を開きます。

## ファイル

- `index.html` — カラーコード変換・ピッカー・和色検索（ライブラリ依存なし）
- `manifest.webmanifest` — 名前・表示設定・アイコン
- `service-worker.js` — インストール後のオフライン用キャッシュ
- `icons/` — PNGアイコンとマスク対応アイコン
- `favicon.ico` — ブラウザタブ用

HTMLを更新するときは `service-worker.js` の `CACHE_NAME` の番号を変更すると、更新後のキャッシュへの切替を確実に行えます。

## 配色パレット（v5）

- 日本の伝統色プリセットを廃止し、現在の色から生成する配色候補へ置き換えました。
- 近似色・補色・類似色・分裂補色・トライアド・同系色の濃淡を表示します。
- 色の帯／HEXテキストを押すと選択色を変更。隣のコピーボタンでHEXだけコピーします。
- 配色はHSL色相環と彩度・明度を利用した候補です。色差に基づく類似色検索や印刷保証値ではありません。
- 既存の和色名検索／近似和色名表示、RGB・CMYK・Lab・HSB変換、三角型／四角型ピッカーは維持。
